# Limitações conhecidas

1. O acesso à internet, navegação visual e captura de apps externos depende do host. Skills não fornecem essas ferramentas automaticamente.
2. Interfaces são dinâmicas: versão, país, cohort, assinatura e login mudam a UX. Uma fonte pública não garante experiência universal.
3. Sem engenharia de experimentos real e dados do projeto, não inferimos ganho de retenção/conversão. Benchmarks só sugerem hipóteses.
4. Não há acesso legitimado a algoritmos, experimentos internos, decisões de PM ou código proprietário dos concorrentes.
5. Apenas especificar regra/evento não executa mudança no app; requer ferramentas, permissão e testes.
6. A preparação de manifesto plugin não garante disponibilidade/publicação no ChatGPT.
7. Dado o caráter sensível de pesquisa envolvendo comportamento, ética e privacidade sempre prevalecem sobre potencial de crescimento.
